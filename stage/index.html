画面内字幕层（推流可见）

位置以歌词层为基准再往下 N px（默认 200，即 calc(50% + 200px)），水平居中、带阴影；矮窗口自动减行数（防被裁）。
隐私打码默认开：只作用于画面层（和连线时的遮罩提示）——场次ID / 推流端UID / 频道ID 显示成 ***；右侧面板保留原始 ID 便于排查。点「保存设置」即时生效，不用刷新。

弹幕直播间

弹幕主播模式

优先级：歌曲 > 打字聊天 > 弹幕。每轮选中一条弹幕接话，附近发言只作背景；默认只回答，不复读原文，过期内容会跳过。
顶栏显示正在准备回复或语音发送中，并标明本轮回应对象。点「保存设置」即时生效。
